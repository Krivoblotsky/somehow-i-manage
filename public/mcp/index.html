For AI assistants

Your people, in every assistant you use.

Somehow I Manage has a Model Context Protocol (MCP) server. Connect it to Claude, ChatGPT, Cursor, VS Code or any other MCP client and the assistant can read and update your people, tasks, notes and projects, as you: “what is open with Vira?”, “prepare my 1:1 with Anton”, “add a task with Emily: draft the hiring plan by Friday”.

The address

https://mvpbxmlczninyqsyjhqh.supabase.co/functions/v1/mcp

That is all a client needs. On the first use it sends you to sign in (Google, Microsoft or a passkey) and to a consent screen where you allow that client once. After that it works as you, until you disconnect it in Account & sync inside the app.

Where to put it

Claude Code claude mcp add --transport http somehow-i-manage https://mvpbxmlczninyqsyjhqh.supabase.co/functions/v1/mcp, then /mcp to sign in
Claude (web, desktop, mobile) Settings → Connectors → Add custom connector → paste the address
ChatGPT Settings → Connectors (developer mode) → add the address
Cursor .cursor/mcp.json: { "mcpServers": { "somehow-i-manage": { "url": "…/functions/v1/mcp" } } }
VS Code .vscode/mcp.json: { "servers": { "somehow-i-manage": { "type": "http", "url": "…/functions/v1/mcp" } } }

What the assistant can do

list_people Everyone, with what is open with each of them, their last 1:1 and their projects.
get_person One person’s page: open tasks (urgent first), notes, what got done recently.
prepare_one_on_one The agenda for a 1:1, the way the app builds it.
whats_due Tasks overdue or due in the coming days, across everyone.
search People, tasks, notes and projects by words.
add_task, add_note, add_person New things, with a person; tasks take a due date, an urgent flag and a project.
update_item, complete_task, move_item, delete_item Changes to what is there.
list_projects, create_project The projects that cut across people.

What it means for your data

The server runs next to your data, in the same Supabase project the app syncs to, and every request carries your own sign-in. It sees exactly what you can see and nothing else; the assistant never gets a key of its own. Changes it makes arrive on your devices through the normal sync, like an edit from another device. You can see every connected assistant and disconnect it at any time in Account & sync. The privacy policy has the rest.

The server is open source, like the app: supabase/functions/mcp.
